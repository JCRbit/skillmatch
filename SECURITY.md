# Security policy

Este proyecto es una prueba de concepto en desarrollo; no introducir datos reales de candidatos ni credenciales de producción.

Para reportar un problema de seguridad, contactar al mantenedor designado por el equipo por un canal privado acordado. No abrir un issue público con CVs, datos personales, tokens o detalles explotables.

El equipo debe designar owner y canal de seguridad antes de despliegue real. No existe aún una promesa de SLA de respuesta.
