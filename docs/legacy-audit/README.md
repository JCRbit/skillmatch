# Legacy audit artefacts

Guardar aquí solo informes y outputs sanitizados del análisis del repositorio legacy. No copiar datos fuente, CVs, `.env`, tokens, dumps ni credenciales.

Outputs obligatorios:

1. `01-repository-inventory.md`
2. `02-architecture-map.md`
3. `03-dependencies-and-licenses.md`
4. `04-security-and-data-risks.md`
5. `05-data-quality-and-reproducibility.md`
6. `06-reuse-register.csv`
7. `07-test-and-runbook-findings.md`
8. `08-reconstruction-plan.md`
9. `UNKNOWNs.md`

El archivo `generated/` puede contener inventories automáticos; revisar y sanitizar antes de commit. Los hallazgos manuales deben referenciar el commit SHA auditado.
